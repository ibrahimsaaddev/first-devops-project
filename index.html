Who I Am

I'm Ibrahim, a fresh graduate from the Faculty of Commerce (English Section) — MIS department — where I got my first taste of IT fundamentals like networking, programming, and business thinking all in one place.

During my studies, I discovered a passion for the infrastructure side of tech. I fell in love with DevOps — the idea of bridging development and operations, automating everything, and shipping faster without breaking things.

I applied for the ITI scholarship but got rejected. Instead of stopping, I opened my laptop and started learning on my own. That decision changed everything.

I believe the best way to learn is to build real things. No Docker first — I wanted to feel the pain of manual deployment so that when Docker came along, I'd truly appreciate what it solves.

The Road So Far

Faculty of Commerce — MIS

Where It All Started

Studied Management Information Systems at the English section of the Faculty of Commerce. Got exposed to networking, programming fundamentals, databases, and business — an unusual but powerful mix that shaped how I think about tech.

After Graduation

Discovered DevOps — Applied for ITI

Found my passion in DevOps — the culture of automation, reliability, and continuous delivery. Applied for the ITI scholarship to accelerate my learning, but got rejected. I refused to let that be the end of the story.

Self-Learning Phase — Started

Linux, Bash, Networking & Python

Opened my laptop and started building the foundation myself. Learned Linux from the ground up, wrote Bash scripts, reinforced my networking knowledge, and picked up Python to automate tasks. Everything hands-on, everything practical.

Certification

AWS Cloud Practitioner ✓

Earned my first cloud certification — AWS Cloud Practitioner. This wasn't just a badge; it was proof that I could study, commit, and deliver results on my own terms.

☁️ AWS Certified — Cloud Practitioner

First Real Project

Deployed My First Web App — On EC2, No Docker

Built and deployed a Flask web app — intentionally without Docker. Set up an Ubuntu VM locally using VirtualBox, configured Gunicorn as the app server, Nginx as the reverse proxy, set up service logging with systemd, used Git & GitHub for version control, then launched the whole thing on an AWS EC2 instance — managed entirely from the terminal. A small site, but a massive milestone.

Next Chapter — In Progress

Docker, Kubernetes & Beyond

Now that I've felt the complexity of manual deployment, I'm ready to learn Docker — and I'll appreciate every single layer of abstraction it provides. After that: Kubernetes, Terraform, and CI/CD pipelines. The journey continues.
